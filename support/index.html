영업일 기준 3일 안에 답장하는 것을 목표로 합니다.

문의할 때 기기 모델, iOS 버전, 문제가 생긴 화면과 시각, 가능하면 스크린샷을 함께 보내 주시면 빨리 확인할 수 있습니다. 결제 문제라면 Apple 주문 번호(Apple이 보낸 영수증 이메일이나 reportaproblem.apple.com에서 확인)를 적어 주세요.

자주 묻는 질문

구매한 상품을 다시 받고 싶어요(구매 복원)

게임에서 상점 → 구매 복원을 누르세요. 「성운석과 패키지」 목록 아래의 구매 복원 버튼도 같은 기능입니다. 같은 Apple 계정으로 산 패키지와 구독을 다시 확인해 계정에 반영합니다.

성운석처럼 이미 지급된 소모형 아이템은 App Store의 복원 대상이 아니며 게임 계정에 저장되어 있습니다. 기기를 바꿀 때는 아래의 계정 이전 코드를 쓰세요.

결제했는데 아이템이 들어오지 않았어요

인터넷 연결을 확인한 뒤 상점을 다시 열거나 구매 복원을 눌러 주세요. 결제가 확인되면 자동으로 지급됩니다. 그래도 들어오지 않으면 Apple 주문 번호, 결제 일시, 상품 이름을 적어 이메일로 알려 주세요.

새 기기로 옮기고 싶어요 / 진행이 사라졌어요

진화 군단은 로그인 없이 익명 계정으로 저장됩니다. 기기를 바꾸기 전에 이전 기기에서 설정 → 계정 이전 → 이전 코드 만들기를 누르고, 새 기기에서 앱을 설치한 직후 설정 → 계정 이전 → 이전 코드 입력에 코드를 넣으세요. 코드는 7일 동안 한 번만 쓸 수 있고, 새 기기에 이미 진행 기록이 있으면 입력할 수 없습니다(앱을 다시 설치한 뒤 바로 입력하세요).

이전 코드 없이 앱을 지웠거나 기기를 잃어버린 경우, 익명 계정은 되찾기 어렵습니다. 구매한 적이 있다면 Apple 주문 번호를 적어 이메일로 알려 주세요. 구매 기록으로 계정을 찾을 수 있는지 확인해 도와드립니다.

이전 코드를 가진 사람은 누구나 계정을 가져갈 수 있습니다. 다른 사람에게 알려 주지 마세요.

계정을 삭제하고 싶어요

게임에서 설정 → 계정 삭제를 누르고 확인하면 계정과 진행 기록이 바로 지워집니다. 앱을 이미 지웠다면 계정 삭제 요청 페이지의 방법으로 이메일로 요청할 수 있습니다.

계정을 삭제해도 App Store 구독은 해지되지 않으니, 구독 중이라면 먼저 해지해 주세요.

별빛 후원 월정액(구독)을 해지하고 싶어요

iPhone의 설정 → [사용자 이름] → 구독 → 진화 군단에서 구독 취소를 누르세요. App Store 앱 오른쪽 위의 계정 아이콘 → 구독에서도 할 수 있습니다. 현재 기간이 끝나기 최소 24시간 전에 해지해야 다음 달 요금이 청구되지 않으며, 해지해도 이미 결제한 기간이 끝날 때까지 혜택이 유지됩니다.

환불을 받고 싶어요

App Store에서 결제한 상품의 환불은 Apple이 처리합니다. reportaproblem.apple.com에서 요청해 주세요. 회사는 결제 정보를 갖고 있지 않아 직접 환불할 수 없습니다. 자세한 기준은 이용약관 제7조에 있습니다.

소환 확률은 어디서 보나요?

게임의 성장 → 확률·지급·천장 안내와 이 사이트의 확률 정보 페이지에서 등급별 확률, 지급 내용, 천장을 모두 볼 수 있습니다.

통계 전송이나 오류 보고를 끄고 싶어요

설정 → 사용 데이터 보내기와 설정 → 오류 보고 보내기를 끄면 됩니다. 사용 데이터는 처음부터 꺼져 있고, 동의한 경우에만 켜집니다.

영어로 바꾸고 싶어요

설정 → English를 켜면 영어로 바뀝니다. 끄면 한국어로 돌아옵니다.
